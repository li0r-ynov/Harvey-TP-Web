# TP-Jeu d’aventure

Un jeu d’aventure textuel où le héros avance de page en page en faisant des choix. Chaque décision mène à
une nouvelle page 

# Fonctionnalités

-pages html interconnectées

# Technologies utilisées

- **Langage :** HTML. Le HTML (pour HyperText Markup Language) est le langage informatique standard utilisé pour créer et structurer le contenu des pages web. Il agit comme le squelette ou la structure de base d'un site internet

- **Outils :** VS Code, GitHub, Google, YouTube et la documentation officielle de Go.

# Le dépôt

git clone https://github.com/li0r-ynov/Harvey-TP-Web

# Installation

Étapes :

- Installer VS Code sur votre PC.
- Installer Git.
- Installer le langage de programmation Go.
- Copier l'adresse du dépôt GitHub : https://github.com/li0r-ynov/Harvey-TP-Web
- Ouvrir l'Explorateur de fichiers.
- Sélectionner un dossier dans lequel placer le projet Go-Reloaded.
- Aller dans la barre d'adresse et écrire `cmd`.
- Écrire la commande suivante : git clone https://github.com/li0r-ynov/Harvey-TP-Web
- Retourner dans votre dossier et vérifier que le nouveau dossier est apparu.
- Ouvrir VS Code et aller dans l'onglet « File ».
- Cliquer sur « Open Folder ».
- Sélectionner le dossier que vous venez de créer.

# Utilisation

-Commande pour lancer l'exécution du jeu d'aventure : go live en bas à droite de VS code

-Commencer le jeu en appuyant sur "start your journey", suivre les pages, une fois retoruner au menu après la pages 5 cliquer sur "continue your journey "pour contineur ou reset pour recommencer le jeu.
